# Reference analysis

How to learn from work you admire without absorbing it.

## The distinction that matters

A reference contributes a **quality**. It never contributes a **layout**.

Qualities are transferable and legitimate: rhythm, spatial idea, typographic
behaviour, motion quality, media treatment, navigation behaviour, an interaction
principle. They are ways of doing something, and they survive being applied to
completely different content.

Structures and identities are not: page composition, section order, colour
system, typeface pairing, choreography, brand expression. Taking those produces a
site that is recognisably someone else's, and it is both a professional and a
legal problem.

The practical test: **could an informed person look at the built result and name
the reference?** If yes, too much came across.

## What to record

Every reference gets a row in the Creative Intent's References table.

| Field | What it captures |
|---|---|
| Reference | What it is, and where. |
| Quality admired | The transferable property. Name the *behaviour*, not the look. |
| Applicability | Why that quality serves this client's argument. |
| Deliberate delta | What is intentionally different. This is the field that does the work. |
| Must not copy | The specific thing that would be copying if it came across. |

A row whose *deliberate delta* is empty is a warning sign: it usually means the
reference is being used as a template and nobody has decided what is different
yet.

## Worked example

From northline's creative contract, which used three studio sites to calibrate:

> Marvell/Humaan, Kadean/Atomicdust and Telha Clarke are used to calibrate the
> professional division only. No branding, asset, copy, layout, colour or
> choreography is taken from any of them. The technical-drawing direction is
> derived from this trade's own documentation conventions, which are not any
> studio's protected expression.

Note what makes that defensible: the references set a **standard**, and the actual
creative direction comes from somewhere else entirely — the client's own trade
conventions. That is the healthiest relationship a delivery can have with its
references.

## Better sources than other websites

The strongest directions usually come from outside web design:

- the client's own trade documentation and instruments;
- how the client's customers actually make the decision;
- the physical materials of the work;
- print, editorial, signage, technical drawing, cartography;
- the constraint the client has that competitors do not.

A site whose references are all other websites in the same trade will look like
other websites in the same trade.

## Copyright and asset boundaries

- No reference asset — image, font file, icon, video, copy — is used in a
  delivery. `REFERENCE_ONLY` media must never reach a client artifact.
- Licensed typefaces are licensed for this client's use, or not used.
- "Inspired by" is not a licence.

## When a reference is doing too much

Ask what remains of the direction if the reference is removed. If the answer is
"not much", the delivery does not have a direction yet — it has a reference and a
recolour.
