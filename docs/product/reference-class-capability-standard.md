# Premium Website Reference-Class Capability Standard

## Purpose

This is a platform-ceiling gate, not a requirement that every client purchase
maximum motion or bespoke production.

The Website Platform must demonstrate that it can produce a client-specific site
in the same professional division as strong custom websites in the Australian
A$25k–50k class while preserving Proportion's accessibility, performance,
portability and isolated-delivery invariants.

## Reference method

Use a bounded reference set:

- one primary creative/art-direction reference;
- one information-architecture/project-storytelling reference where needed;
- one motion-engineering reference where needed.

Extract capability, not copyrighted expression. Do not copy brand, assets, copy,
exact layout, code or choreography.

## Required capability dimensions

### Information architecture

- multi-page routes are natural when content depth warrants them;
- Projects/Case Studies are first-class index/detail content;
- services, projects, locations and related content link coherently;
- navigation labels are concise and independent from page headings;
- Search complements navigation and taxonomy rather than rescuing them.

### Art direction

- a clear client-specific creative thesis is visible;
- composition materially changes according to content and route purpose;
- typography, imagery, density and whitespace behave as narrative material;
- the result does not read as repeated shared sections or a theme marketplace;
- desktop and mobile both look intentionally art-directed.

### Motion and interaction

- motion has a customer, narrative or brand purpose;
- at least one memorable Signature interaction is present in the proof;
- hover, pointer, focus and scroll states are coherent;
- complex interactivity is route/component scoped and lazy where practical;
- reduced-motion behavior is intentionally designed;
- sites that do not use rich motion pay no global motion-library/runtime tax.

### Project storytelling

- project detail pages support a substantial narrative, not only a gallery;
- media sequencing, facts, challenge/approach/outcome and related projects are
  available when supported by truthful evidence;
- project browsing and next-step conversion remain clear.

### Engineering

- production build and published CI pass;
- keyboard, touch, accessibility, metadata/schema and forms pass;
- constrained CPU/network runtime remains smooth;
- client-specific source remains isolated and maintainable;
- standalone artifact builds without private Platform access;
- asset provenance and alt/crop ownership are explicit.

## Gate rule

Do not average a material failure away.

- beautiful desktop + weak mobile = FAIL;
- beautiful animation + sticky runtime = FAIL;
- technical green + obvious template smell = FAIL;
- spectacular homepage + weak Projects architecture = FAIL;
- search-dependent findability = FAIL;
- fabricated proof presented as real = FAIL.

Founder creative sign-off and one fresh independent craft/customer-task review are
required for the exact deployed candidate.
